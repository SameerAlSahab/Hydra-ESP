# Support

Need help with Hydra-ESP? Use the right channel so your question or report doesn't get lost.

## General Questions

Not sure if your board is supported, or need help using a feature? Ask in [Discussions](https://github.com/SameerAlSahab/Hydra-ESP/discussions).

Please use Issues for actual bugs and feature requests, rather than general questions.

## Bug Reports

Found something that isn't working as expected? [Open a bug report](https://github.com/SameerAlSahab/Hydra-ESP/issues/new?template=bug_report.md).

Include your board model, ESP-IDF version, and serial logs if available. The more detail you provide, the easier it is to reproduce and fix the problem.

## Feature Requests and Modules

Have an idea for a new feature or module? [Open a feature request](https://github.com/SameerAlSahab/Hydra-ESP/issues/new?template=feature_request.md).

If you'd like to contribute the implementation yourself, pull requests are welcome. Check [CONTRIBUTING.md](CONTRIBUTING.md) before getting started.

## Security Issues

Found a potential vulnerability? **Don't post it publicly.** Follow the private reporting instructions in [SECURITY.md](SECURITY.md).

## Build and Flash Problems

Before asking for help, check the [ESP-IDF setup guide](https://docs.espressif.com/projects/esp-idf/en/latest/esp32/get-started/). A mismatched ESP-IDF version is a common cause of build problems.

Still stuck? Open a thread in [Discussions](https://github.com/SameerAlSahab/Hydra-ESP/discussions) with the full error output, your board model, and your ESP-IDF version.

That should give others enough information to help without having to guess your setup.
